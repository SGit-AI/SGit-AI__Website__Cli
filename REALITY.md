# Reality: what exists, at v0.2.0 (20 October 2026)

The rule, from the SG/Send repository's Librarian: a feature that is not in this file does not exist, and nobody may say a thing works because a brief describes it. Kept current by whoever ships.

## Exists

| | |
|---|---|
| **The site** | Static HTML generated by `admin/build/build.py` from `admin/content/`, deployed to GitHub Pages from `dev` by `.github/workflows/deploy-pages.yml`; CNAME `cli.sgit.ai` |
| **27 pages moved from sgit.ai** | At their sgit.ai paths, text unchanged, from sgit.ai site v0.7.87; each states where it came from ([the list](/admin/moved.html)) |
| **The command reference** | 33 pages, one per top-level command, covering all 158 commands of sgit-ai v0.23.0, generated from `sgit help all --format json`; the JSON is published beside it |
| **22 research documents, in 7 topics** | Under `/research/`, from `SGit-AI__CLI` at `5473571` (branch `claude/charming-babbage-5hzcxq`), `team/humans/dinis_cruz/claude-code-web/`, 2 to 16 October 2026, bodies as written; one page per topic with its question and status (since v0.2.0) |
| **10 articles in the newsroom's format** | Under `/articles/`: seven converted from the CLI team's drafts of 16 and 20 October with their text as drafted, two from Dinis Cruz's memos, one by the build agent; each with a lead SVG figure drawn by `admin/build/make_figures.py`; held to the format by the gate (since v0.2.0) |
| **The 21 v0.1 article addresses** | Each is a page that sends the reader to the document's address under `/research/`; a page with a refresh, since GitHub Pages has no redirect rules |
| **The team page** | Who writes here and under which name: Dinis Cruz, cli.build, the CLI team |
| **The briefs** | Both published in full: the voice brief with the initial prompt, and the second brief of the same day |
| **Machine-readable twins** | A `.md` twin for every page, `llms.txt`, `llms-full.txt`, `sitemap.xml`, all generated |
| **The gate** | `admin/build/validate.js`: build freshness, version agreement, links, canonical host, twins, orphans, leak tripwire; runs in CI before tag and deploy |
| **The live site** | https://cli.sgit.ai served v0.1.1 on 20 October 2026, checked against `assets/version.js` after the deploy; the github.io address redirects to it |
| **Versioning** | `admin/build/version.txt`, badge on every page via `assets/version.js`, release history, tags `vX.Y.Z` made by CI |

## Does not exist yet

| | |
|---|---|
| **Redirects on sgit.ai** | The moved pages still exist on sgit.ai, and nothing there points here yet. Requested in [the corrections file](/admin/corrections.html) |
| **The review folder** | `review/` (intent from the brief, code derived from the tree, commits read upwards) is required by the estate's guidance from the first commit and is not built |
| **Roles and a board** | The team page names who writes; no roles as files and no board yet |
| **A release script** | Releasing is the four commands on [the engineering page](/admin/index.html); nothing polls the live site for the new version |
| **Automatic reference updates** | The reference JSON is regenerated by hand per CLI release; nothing in the CLI's pipeline sends it here |
| **A pipeline from the CLI repository** | `import_cli_research.py` is run by hand, from a list; a new CLI draft becomes an article by a conversion done by hand |
| **Review of the converted articles** | The seven articles converted from drafts, and the summaries written in Dinis Cruz's voice, have not been read by him yet |
| **Search** | None. `llms.txt` and the docs hub are the indexes |

## Proposed, not built

- The CLI's release pipeline writing `sgit help all --format json` into this repository, so the reference moves with every release.
- Per-version reference pages (`/reference/v0.23.0/`), so a reader on an older CLI reads the surface they have.
