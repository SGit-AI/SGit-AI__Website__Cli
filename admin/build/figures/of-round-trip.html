The round trip, run today with the commands sgit ships

From a hosted vault to a file sealed to one person's public key, and back to a working clone, with sgit-ai 0.23.0 in a cloud sandbox on 21 October 2026. Every step is a shipped command or a plain zip; what is missing is one command that does it all, and the times are from one run.

Steps 3 and 4 are optional

Without them the file is already ciphertext: names are hashes, contents are encrypted, the read key opens it. The seal adds a second lock and hides what a plain zip shows.

The envelope is 1.78 times the zip

Its payload is base64 inside JSON, and the whole is base64 again: 4/3 squared. A binary envelope would be about the zip's size. A finding for the CLI team.

Read-only, by construction

A clone from a folder cannot push back to it. To change the vault, work in a live one and make the file again, or write to it from one writer at a time.
