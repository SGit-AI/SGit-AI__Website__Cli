As the vault grows, a one-folder clone stays flat

Clone time against the number of files in the vault, median of three runs: sgit 0.21.0 against a local vault server over HTTP, four cores, files of random bytes in 20 folders. The one-folder clone takes 5% of the files and barely moves; the full clone grows with the vault.

Full clone

every object, every folder, all of the history: 82.7 MB on disk at 2,000 files.

One folder, --path

the spine of trees to one folder and the files in it: 4.1 MB on disk at 2,000 files.

Ten at once

Ten one-folder clones together: 1.9 s. Ten full clones: 21.1 s, on one server process.
