Requests, not bytes: what each operation costs today and in pack mode

From one cloud sandbox a 28-byte object costs half a second whether it comes through the API or straight from S3, so the number of requests is the cost. Each row is one operation on a vault; the grey bar is today's request count with loose objects through the batch route, the orange bar the expected count in pack mode, drawn to the same scale (capped at 100). The pack-mode figures are arithmetic from measured floors, not measurements: nothing is built. The red row is the exception the bars hide: few requests, but 430 MB where today it is 3 MB.
