sgit and Git, row by row

Sections checked against sgit-ai 0.26.0 and 0.27.0 (28 October), from the sgit CLI team's review of the code and this site's own checks. "No equivalent" means the mainstream Git toolchain and GitHub. Dashed: not built in sgit yet, but buildable on the client without giving up zero knowledge, because Git builds it on the client too.
