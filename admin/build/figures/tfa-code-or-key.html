Without a server, a second factor has to be part of the key, not a code someone checks

A code is only a factor if something that cannot be bypassed checks it. With no server there is nothing to check it, so the second factor must supply bytes the decryption needs. Four candidates for sgit, on the CLI and in the browser:

An authenticator app's code

A CODE · NOT A KEY
  • Google Authenticator, Authy, LastPass, 1Password: TOTP, a 6-digit HMAC of a shared secret and the time.
  • To check it, the client must hold that secret. Whoever can read the vault can read the secret, and make the code.
  • About 20 bits, new every 30 s: too little, and changing too often, to be part of a key.
  • Useful only behind something that checks it: a server, or a person.

A passkey with PRF

A KEY · IN THE BROWSER
  • The authenticator returns 32 fixed bytes for a given input, after the person's touch, face or PIN.
  • Mixed with the vault key by HKDF, they make a key neither half makes alone.
  • pki.sgit.ai already opens vaults this way.
  • Works with iCloud Keychain and Google Password Manager; reported for Windows Hello since early 2026; mixed in third-party password managers.

A security key, from the CLI

A KEY · ON A LAPTOP
  • A YubiKey 5 or similar computes the same kind of secret (CTAP2 hmac-secret) over USB or NFC, after a touch and a PIN.
  • The method Linux uses to unlock disks: systemd-cryptenroll --fido2-device.
  • Python reaches it through python-fido2.
  • No use in a cloud container: there is no key to plug in.

A person, for an agent

A CO-SIGNER
  • An agent has no phone and no finger. Its second factor is the person who approves it.
  • The QR handover already works this way: nothing opens until the person carries a sealed key over.
  • Make it part of the key: half on the agent's disk, the other half from the person each session, held only in memory.
Passkeys and security keys can be a factor without a server; an authenticator app's code cannot.cli.sgit.ai · 24 October 2026 · a proposal; support as reported in October 2026
