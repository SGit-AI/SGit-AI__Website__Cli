# Release history

The site's version is in `admin/build/version.txt` and goes up on every push to `dev`; the badge at the top of every page reads it. The command reference carries its own version, the sgit-ai release it was generated from.

|---|---|---|---|
| v0.1.0 | 2026-10-20 | sgit-ai v0.23.0 | The first version, built from [the brief](/briefs/index.html) the same day: 27 pages moved from sgit.ai (site v0.7.87) so the CLI's technical documentation has one home, the command reference generated from `sgit help all --format json` (158 commands), and 23 research documents from the CLI repository (`SGit-AI__CLI` at 5597526) published as articles, with the generator, the gate and the deploy pipeline the sibling sites run. |
