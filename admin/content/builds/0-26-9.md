## What changed {#new}

- **Push collects every commit the host lacks,** with the commit graph's two-sided walk, no cap. Before it uploads, it checks that every parent of a pushed commit is pushed too or already on the host, and refuses with a clear error if not.
- **`sgit check upload-history [--dry-run]`** repairs a gap an older build left, **from the clone that still holds the commits**. If that clone is gone, those commits are lost.
