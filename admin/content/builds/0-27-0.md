## For the release notes of 0.27.0 {#release-notes}

New: `history blame`, `sgit grep`, `log -S`/`-G`, rename detection and `--follow`, commit by path and by hunk, `push` with uncommitted changes, opt-in line-level merge, 64 KB messages, `commit -S` and user signatures with `check verify`, `check upload-history`, faster `pack index verify`.

Fixed: a push of more than 100 commits left a gap on the host (every build since at least 0.26.0); a merge on a fork deeper than 200 commits; commit during an unresolved merge; nested vaults; and the line differ.

Changes that can break a script:
- `commit -m "msg" y`: `y` is now a path.
- `history log/show/diff --json`: a renamed file is in `files_renamed`, no longer in `files_added` and `files_deleted`.
- The patch text of `history show/diff` is `git diff`'s; rename detection is on by default.
- `sgit grep` patterns read like `git grep -E`.
- `sgit.gpgSign`, not Git's `commit.gpgSign`, turns signing on.
- Dev builds are `X.Y.Z.devN` pre-releases; a plain install gets the release.
