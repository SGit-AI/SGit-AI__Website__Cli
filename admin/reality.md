# Reality: what exists, at v0.2.3 (21 October 2026)

The rule, from the SG/Send repository's Librarian: a feature that is not in this file does not exist, and nobody may say a thing works because a brief describes it. Kept current by whoever ships.

## Does not exist yet

| | |
|---|---|
| **HTTPS enforced** | `http://cli.sgit.ai` answers 200 instead of redirecting to HTTPS, so a browser that arrives by http shows "Not Secure"; sgit.ai and newsroom.sgit.ai redirect. The certificate works. The fix is the repository's Settings, Pages, "Enforce HTTPS", which needs a person with admin rights (checked 21 October 2026) |
| **Redirects on sgit.ai** | The moved pages still exist on sgit.ai, and nothing there points here yet. Requested in [the corrections file](../admin/corrections.md) |
| **The review folder** | `review/` (intent from the brief, code derived from the tree, commits read upwards) is required by the estate's guidance from the first commit and is not built |
| **Roles and a board** | The team page names who writes; no roles as files and no board yet |
| **A release script** | Releasing is the four commands on [the engineering page](../admin/index.md); nothing polls the live site for the new version |
| **Automatic reference updates** | The reference JSON is regenerated by hand per CLI release; nothing in the CLI's pipeline sends it here |
| **A pipeline from the CLI repository** | `import_cli_research.py` is run by hand, from a list; a new CLI draft becomes an article by a conversion done by hand |
| **Review of the converted articles** | The eight articles converted from drafts, and the summaries written in Dinis Cruz's voice, have not been read by him yet |
| **Pack mode itself** | Specified, with the review's five decisions taken (21 October, `477d328`), not built. The brief to the SG/Send team is marked parked in the CLI repository; whether that team has read it is not known here |
| **Search** | None. `llms.txt` and the docs hub are the indexes |

## Proposed, not built

- The CLI's release pipeline writing `sgit help all --format json` into this repository, so the reference moves with every release.
- Per-version reference pages (`/reference/v0.23.0/`), so a reader on an older CLI reads the surface they have.
