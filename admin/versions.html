Release history

The site's version is in admin/build/version.txt and goes up on every push to dev; the badge at the top of every page reads it. The command reference carries its own version, the sgit-ai release it was generated from.

VersionDateCommand referenceWhat changed, and why
v0.2.02026-10-20sgit-ai v0.23.0Research and articles become two areas, from the second brief: 22 research documents as written under /research/ in seven topics, each topic a question with what is shipped, designed and absent; ten articles under /articles/ in the newsroom's format send.sgit.ai's guidance sets out, seven of them converted from the CLI team's drafts of 16 and 20 October, with lead figures; the gate holds articles to the format; the 21 v0.1 addresses send the reader on. A minor-version step because addresses moved.
v0.1.22026-10-20sgit-ai v0.23.0The reality file catches up: cli.sgit.ai was checked live after v0.1.1 deployed (DNS, Pages and the dev environment all work), so it moves from "does not exist yet" to "exists".
v0.1.12026-10-20sgit-ai v0.23.0The generator and the gate reach the repository: the Python .gitignore template's build/ rule had kept admin/build/ out of the v0.1.0 commit, so CI could not run validate.js and nothing deployed. .gitignore now re-includes admin/build/.
v0.1.02026-10-20sgit-ai v0.23.0The first version, built from the brief the same day: 27 pages moved from sgit.ai (site v0.7.87) so the CLI's technical documentation has one home, the command reference generated from sgit help all --format json (158 commands), and 23 research documents from the CLI repository (SGit-AI__CLI at 5597526) published as articles, with the generator, the gate and the deploy pipeline the sibling sites run.
