Research

The CLI team's articles, newest first. Each takes one topic, one implementation or one idea as far as the evidence goes: a measurement on a real vault, a design and the review that corrected it, a bug traced to its cause. They are, in the words of the brief, "our new generation of briefs", and this is where they are captured first.

The first 23 were written in the CLI repository between 2 and 16 October 2026 (team/humans/dinis_cruz/claude-code-web/) and are published here as written, each with its source path and commit. The kind on each card says what it is worth: a measurement is numbers from a run; a design, plan or analysis is a proposal, not a shipped feature, unless it says so; a fix or finding names the code.

position

sgit is a standard, not a server: everything in a vault is one hash away

A vault is a set of files laid out by a convention, every immutable object named by the hash of its own ciphertext, so the server is the least interesting part and anything in the path can cache blindly.
