## What changed {#new}

- **`sgit doctor` shows a Signing block** (`--json`: `signing`): whether signing is on and why (`sgit.gpgSign (not set: off)`), the format, the key (with a warning if an SSH key file is missing), the programs, and the allowed-signers and revocation files. Checked: it prints as described.
- **`check verify --require-user-signature`** exempts only the vault's empty first commit (what `sgit init` writes: no parent, an empty tree, no way to pass `-S`). `--limit N` scopes the gate to the newest N commits for a history that started signing later.
- **`check verify --limit N`** checked and reported N + 1 commits; now N.
