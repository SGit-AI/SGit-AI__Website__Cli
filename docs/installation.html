Installation

Moved from sgit.ai. This page was sgit.ai/docs/installation.html (sgit.ai site v0.7.87), moved here on 20 October 2026 as cli.sgit.ai becomes the CLI's main documentation. The text is as it was; links to pages that moved now stay on this site. What moved, and why.

Pure Python, two runtime dependencies. Python 3.11 or newer.

$ pip install sgit-ai
# or, on externally-managed systems:
$ pipx install sgit-ai

This installs two entry points: sgit and sgit-ai (they are identical, use whichever you like).

Verify

$ sgit version
sgit-ai v0.18.0
$ sgit doctor
✓ remote reachable   ✓ TLS ok   ✓ config valid

sgit doctor checks connectivity and configuration and prints per-OS fix instructions for the common problems (including SSL certificate issues). Add --json if a script or an agent is doing the checking.

Upgrade

$ sgit update   # wraps pip install --upgrade sgit-ai

The current release is 0.21.0, published 10 October 2026. If sgit version still shows an older number after sgit update, you have more than one Python environment; run python -m pip install --upgrade sgit-ai in the one your tools use. What changed, what now refuses and what to do: Update sgit-ai to 0.21.0. Coming from 0.17 or older, also read Update sgit-ai to 0.18.0 for the clone command.
