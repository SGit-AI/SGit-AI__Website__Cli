sgit cache

Declare cached paths (fast single-request reads).

Generated from sgit help all --format json, sgit-ai v0.23.0. 4 subcommands below. To change this page, change the command's register() in the CLI and regenerate.

sgit cache

Subcommands

  • sgit cache add: Declare a path as cached
  • sgit cache repair: Reconcile cache objects with HEAD; drop orphans and duplicates
  • sgit cache rm: Undeclare a cached path
  • sgit cache status: List cached paths and freshness

sgit cache add

Declare a path as cached

sgit cache add [options] <path> [directory]
ArgumentWhat it is
pathrequiredVault-relative path (file or folder)
directoryoptionalVault directory (default: .)
OptionWhat it does
--pointerStore a locator (blob_id/tree_id) instead of the value
--valueStore a copy of the file content (files only)

sgit cache repair

Reconcile cache objects with HEAD; drop orphans and duplicates

sgit cache repair [options] [directory]
ArgumentWhat it is
directoryoptionalVault directory (default: .)
OptionWhat it does
--dry-runReport what would change without changing anything
--jsonOutput as JSON

sgit cache rm

Undeclare a cached path

sgit cache rm <path> [directory]
ArgumentWhat it is
pathrequiredVault-relative path
directoryoptionalVault directory (default: .)

sgit cache status

List cached paths and freshness

sgit cache status [options] [directory]
ArgumentWhat it is
directoryoptionalVault directory (default: .)
OptionWhat it does
--jsonOutput as JSON
