# sgit doctor

Check remote connectivity and configuration.

*Generated from `sgit help all --format json`, sgit-ai v0.23.0. No subcommands. To change this page, change the command's `register()` in the CLI and regenerate.*

```text
sgit doctor [options]
```

| Option | What it does |
|---|---|
| `--directory`, `-d` | Vault directory (default: .) |
| `--json` | Output JSON report |
| `--remote` | Remote name to check (default: current vault default) |
| `--timeout` | Timeout per check in seconds (default: 5) |
| `--write-probe` | Also probe write access (writes and deletes a small test object) |
