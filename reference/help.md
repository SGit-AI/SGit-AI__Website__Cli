# sgit help

Show help (use `sgit help all` for full surface).

*Generated from `sgit help all --format json`, sgit-ai v0.26.0. No subcommands. To change this page, change the command's `register()` in the CLI and regenerate.*

```text
sgit help [options] [topic]
```

| Argument | | What it is |
|---|---|---|
| `topic` | optional | Command name or "all" to show the full command surface |

| Option | What it does |
|---|---|
| `--format` | text: human help (default); json: diffable contract; markdown: docs page; llms: llms.txt index One of: `json`, `llms`, `markdown`, `text`. |
| `--output`, `-o` | Write to FILE instead of stdout (non-text formats) |
