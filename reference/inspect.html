sgit inspect

Read-only vault inspection tools.

Generated from sgit help all --format json, sgit-ai v0.24.0. 6 subcommands below. To change this page, change the command's register() in the CLI and regenerate.

sgit inspect

Subcommands

  • sgit inspect diff-state: Compare two vault dumps and report divergences
  • sgit inspect ignored: Audit what is excluded from vault tracking
  • sgit inspect object: Show object details
  • sgit inspect stats: Show object store statistics
  • sgit inspect tree: Show current tree entries
  • sgit inspect vault: Show vault state overview

sgit inspect diff-state

Compare two vault dumps and report divergences

sgit inspect diff-state [options] [dump_a] [dump_b] [directory]
ArgumentWhat it is
dump_aoptionalPath to first dump JSON file
dump_boptionalPath to second dump JSON file
directoryoptionalVault directory for on-the-fly dump (default: .)
OptionWhat it does
--localProduce local dump on the fly
--remoteProduce remote dump on the fly

sgit inspect ignored

Audit what is excluded from vault tracking

sgit inspect ignored [options] [directory]
ArgumentWhat it is
directoryoptionalVault directory (default: .)
OptionWhat it does
--rulesPrint the curated ignore sets (no filesystem walk)
--whyExplain whether and why <path> is ignored or tracked

sgit inspect object

Show object details

sgit inspect object <object_id> [directory]
ArgumentWhat it is
object_idrequiredObject ID (12-char hex)
directoryoptionalVault directory (default: .)

sgit inspect stats

Show object store statistics

sgit inspect stats [directory]
ArgumentWhat it is
directoryoptionalVault directory (default: .)

sgit inspect tree

Show current tree entries

sgit inspect tree [options] [directory]
ArgumentWhat it is
directoryoptionalVault directory (default: .)
OptionWhat it does
--vault-keyVault key (auto-read from .sg_vault/local/vault_key if omitted)

Show vault state overview
