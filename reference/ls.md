# sgit ls

List vault files with fetch status.

*Generated from `sgit help all --format json`, sgit-ai v0.23.0. No subcommands. To change this page, change the command's `register()` in the CLI and regenerate.*

```text
sgit ls [options] [path] [directory]
```

| Argument | | What it is |
|---|---|---|
| `path` | optional | Subdirectory or file path (default: root) |
| `directory` | optional | Vault directory (default: .) |

| Option | What it does |
|---|---|
| `--ids` | Include blob IDs in output |
| `--json` | Output full entry metadata as JSON array |
