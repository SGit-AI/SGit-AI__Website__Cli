sgit pack

Pack vaults: objects as zips on the host (import, export, compact, ls, verify, stats).

Generated from sgit help all --format json, sgit-ai v0.26.0. 14 subcommands below. To change this page, change the command's register() in the CLI and regenerate.

sgit pack [options]
OptionWhat it does
--base-urlAPI base URL (overrides --remote, global --base-url, and saved config)
--no-verify-tlsSkip TLS certificate verification (staging / self-signed only)
--remoteUse the named remote (URL + tls_verify from saved config); overrides the default remote for this command
--tokenSG/Send access token (overrides global --token and saved config)
--transportHow to reach the vault: auto (default — a folder is local, an http(s) host is api unless its batch endpoint is absent), api (live SG/API), static (any GET host, read-only), local (a folder, read-only) One of: api, auto, local, static.
--verify-tlsVerify TLS certificates (default)

Subcommands

  • sgit pack compact: One snapshot of the head; absorbed, superseded and orphan packs move to archive/
  • sgit pack export: Rewrite a pack-vault clone into a NEW normal vault (new key; source untouched)
  • sgit pack import: Rewrite a full clone of a normal vault into a NEW pack vault (new key; source untouched)
  • sgit pack index: Index packs beside the data packs (build the missing ones, verify, stats)
  • sgit pack index build: Write the index pack of every data pack that lacks one (needs the write key)
  • sgit pack index stats: Index packs per folder, sizes, gaps, generations
  • sgit pack index verify: Check every index pack against its data pack and the trees (read-only)
  • sgit pack ls: List the packs on the host
  • sgit pack stats: Packs and bytes on the host; local compression ratio
  • sgit pack store: The local pack store of a clone made with --pack-store (packs kept in place)
  • sgit pack store extract: Write every packed object loose and drop the kept packs: an ordinary clone from here
  • sgit pack store rebuild: Rebuild the object table from the kept pack files
  • sgit pack store status: Packs kept, objects read from them, loose objects
  • sgit pack verify: Check every pack member against its content address
