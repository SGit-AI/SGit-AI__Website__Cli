cli.sgit.ai / Command reference / sgit push

sgit push

Push clone branch to the named branch.

Generated from sgit help all --format json, sgit-ai v0.26.8. No subcommands. To change this page, change the command's register() in the CLI and regenerate.

sgit push [options] [directory]
ArgumentWhat it is
directoryoptionalVault directory (default: .)
OptionWhat it does
--base-urlAPI base URL (overrides --remote, global --base-url, and saved config)
--branch-onlyPush clone branch objects and ref without updating named branch
--forceOverwrite remote ref unconditionally (no CAS check). Use after sgit history reset <commit> to rewind a branch.
--force-with-leaseForce, but only if the remote branch is still where this clone last saw it (or at COMMIT); refuses, writing nothing, if a teammate pushed since.
--no-verify-tlsSkip TLS certificate verification (staging / self-signed only)
--remoteUse the named remote (URL + tls_verify from saved config); overrides the default remote for this command
--tokenSG/Send access token (overrides global --token and saved config)
--transportHow to reach the vault: auto (default — a folder is local, an http(s) host is api unless its batch endpoint is absent), api (live SG/API), static (any GET host, read-only), local (a folder, read-only) One of: api, auto, local, static.
--verify-tlsVerify TLS certificates (default)
