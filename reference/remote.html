sgit remote

Manage vault remotes (alias for sgit vault remote).

Generated from sgit help all --format json, sgit-ai v0.26.8. 7 subcommands below. To change this page, change the command's register() in the CLI and regenerate.

sgit remote

Subcommands

  • sgit remote add: Add a remote
  • sgit remote list: List configured remotes
  • sgit remote remove: Remove a remote
  • sgit remote rename: Rename a remote
  • sgit remote set-default: Set the default remote
  • sgit remote set-url: Update the URL of a remote
  • sgit remote show: Show details of a remote

sgit remote add

Add a remote

sgit remote add [options] <name> <url> [remote_vault_id]
ArgumentWhat it is
namerequiredRemote name (e.g. origin)
urlrequiredRemote API URL
remote_vault_idoptionalRemote vault ID (defaults to current vault)
OptionWhat it does
--defaultSet as the default remote
--directory, -dVault directory (default: .)
--no-health-checkSkip connectivity check on add
--no-verify-tlsSkip TLS certificate verification

sgit remote list

List configured remotes

sgit remote list [options]
OptionWhat it does
--directory, -dVault directory (default: .)

sgit remote remove

Remove a remote

sgit remote remove [options] <name>
ArgumentWhat it is
namerequiredRemote name to remove
OptionWhat it does
--directory, -dVault directory (default: .)

sgit remote rename

Rename a remote

sgit remote rename [options] <old_name> <new_name>
ArgumentWhat it is
old_namerequiredCurrent remote name
new_namerequiredNew remote name
OptionWhat it does
--directory, -dVault directory (default: .)

sgit remote set-default

Set the default remote

sgit remote set-default [options] <name>
ArgumentWhat it is
namerequiredRemote name to set as default
OptionWhat it does
--directory, -dVault directory (default: .)

sgit remote set-url

Update the URL of a remote

sgit remote set-url [options] <name> <new_url>
ArgumentWhat it is
namerequiredRemote name
new_urlrequiredNew API URL
OptionWhat it does
--directory, -dVault directory (default: .)
--no-health-checkSkip connectivity check against the new URL

sgit remote show

Show details of a remote

sgit remote show [options] <name>
ArgumentWhat it is
namerequiredRemote name
OptionWhat it does
--directory, -dVault directory (default: .)
