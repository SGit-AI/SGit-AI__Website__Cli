sgit serve

Run this vault on your machine: the vault UI + API in a container (Docker, Podman, Apple container), or --static.

Generated from sgit help all --format json, sgit-ai v0.23.0. 8 subcommands below. To change this page, change the command's register() in the CLI and regenerate.

sgit serve [options]
OptionWhat it does
--bindAddress to bind (default 127.0.0.1; 0.0.0.0 exposes it to your network)
--dataData folder for the server (default: .sg_vault/serve/data in this clone)
--imageImage to run (default diniscruz/sg-send-vault:latest)
--no-pullDo not check for a newer image; use the one already here
--openOpen the UI in a browser
--portPort on this machine (default 8420; the next free one if taken)
--runtimecontainer | docker | podman | nerdctl | finch | uv (default: the first found)
--staticRead-only server for a published vault (default: this vault's .sg_vault/publish/, publishing first if needed)
--ui-dirBuilt vault UI folder (uv engine only)

Subcommands

  • sgit serve install: Install a container runtime (shows what, then asks)
  • sgit serve logs: Server output
  • sgit serve pull: Bring work done in the browser into this clone (fast-forward)
  • sgit serve push: Send this clone's commits to the local server
  • sgit serve runtimes: Container runtimes on this machine
  • sgit serve status: Is it running, where, which image
  • sgit serve stop: Stop the local server
  • sgit serve update: Get the newest image and restart (same data)
