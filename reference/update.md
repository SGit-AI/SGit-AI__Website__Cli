# sgit update

Update sgit-ai to the newest build (X.Y.0 is a release, X.Y.N a dev build).

*Generated from `sgit help all --format json`, sgit-ai v0.26.8. No subcommands. To change this page, change the command's `register()` in the CLI and regenerate.*

```text
sgit update [options]
```

| Option | What it does |
|---|---|
| `--pre` | The newest build, dev builds included (the default; kept for scripts) |
| `--stable` | Install the newest release (X.Y.0) instead of the newest dev build |
