sgit vault

Vault management and credential store.

Generated from sgit help all --format json, sgit-ai v0.25.0. 41 subcommands below. To change this page, change the command's register() in the CLI and regenerate.

sgit vault

Subcommands

  • sgit vault add: Store a vault key under an alias
  • sgit vault attach: Bind a key to an existing .sg_vault/bare checkout (e.g. a fresh git clone of a one-repo vault)

  • sgit vault backups: List available backups for a vault
  • sgit vault clean: Remove working copy, keeping bare vault; or prune empty dirs
  • sgit vault delete-on-remote: Hard-delete this vault from the server, keep local clone intact
  • sgit vault derive-keys: Derive vault_id / read_key / write_key / file ids from a vault key or {read_key}:{vault_id} (plumbing: bare hex output, accepts sgit_private_/sgit_public_ prefixes)
  • sgit vault format: Show or raise the vault format gate (object-id width, minimum client, features)
  • sgit vault ignore: Show always-ignored folders, or deliberately remove a now-ignored folder from the vault
  • sgit vault info: Show vault identity, remote, branch, and web URL
  • sgit vault list: List stored vault aliases
  • sgit vault mirror: Copy a published vault you cannot read (custody without access) — keyless, verifiable
  • sgit vault move: Move vault to a new identity (key rotation + optional server move)
  • sgit vault rekey: Replace the vault key and re-encrypt all content
  • sgit vault rekey check: Show vault state without making changes

sgit vault attach

Bind a key to an existing .sg_vault/bare checkout (e.g. a fresh git clone of a one-repo vault)

sgit vault attach [options] [directory]
ArgumentWhat it is
directoryoptionalVault directory (default: .)
OptionWhat it does
--base-urlAPI base URL (overrides --remote, global --base-url, and saved config)
--no-verify-tlsSkip TLS certificate verification (staging / self-signed only)
--read-keyRead key (with --vault-id) -> read-only attach
--remoteUse the named remote (URL + tls_verify from saved config); overrides the default remote for this command
--tokenSG/Send access token (overrides global --token and saved config)
--transportHow to reach the vault: auto (default — a folder is local, an http(s) host is api unless its batch endpoint is absent), api (live SG/API), static (any GET host, read-only), local (a folder, read-only) One of: api, auto, local, static.
--vault-idVault id, required with --read-key
--vault-keyFull vault key -> read-write attach
--verify-tlsVerify TLS certificates (default)

sgit vault derive-keys

Derive vault_id / read_key / write_key / file ids from a vault key or {read_key}:{vault_id} (plumbing: bare hex output, accepts sgit_private_/sgit_public_ prefixes)

sgit vault derive-keys <vault_key>
ArgumentWhat it is
vault_keyrequiredVault key ({passphrase}:{vault_id}), {read_key_hex}:{vault_id}, or either with its sgit_private_vault_/sgit_private_read_/sgit_public_read_ prefix

sgit vault format

Show or raise the vault format gate (object-id width, minimum client, features)

sgit vault format [options] [directory]
ArgumentWhat it is
directoryoptionalVault directory (default: .)
OptionWhat it does
--base-urlAPI base URL
--featureAdd a feature flag (e.g. signatures-required); repeatable
--min-clientRefuse clients older than this version, by name
--remove-featureRemove a feature flag; repeatable
--setRaise the format: 2 = new objects get 128-bit (32-hex) ids; existing objects keep theirs, no move
--tokenAccess token
